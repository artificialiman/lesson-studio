Shortcuts to Relevant Applications

Word • Excel • PowerPoint • Command Prompt • PowerShell • IDEs • SDKs
Why shortcuts matter. Every application you use — whether a word processor, a spreadsheet, a terminal, or a code editor — exposes the same underlying design: a command is bound to a key combination, a menu item, and a programmatic interface. Learning shortcuts is not about memorising keystrokes; it is about learning the grammar each application uses so you can predict unfamiliar bindings. This lesson covers the universal modifier system, then walks through seven application families: Word, Excel, PowerPoint, Command Prompt, PowerShell, IDEs, and SDKs — with principles, exceptions, and the reasoning behind each binding.
Section A

The Universal Modifier System

Before any application-specific detail, you must understand the four modifier keys and what each means. Almost every shortcut is a modifier + a mnemonic letter. Once you know the modifier's role, you can guess the letter.

1. Ctrl (Control) — "Execute a command"

Ctrl is the workhorse. It pairs with a letter that is the first letter of the command. This is the single most reliable rule in computing.

Ctrl + C = Copy  •  Ctrl + V = Paste (adjacent to C on QWERTY)  •  Ctrl + X = Cut (X = scissors)  •  Ctrl + Z = Undo (Z = the last letter, "back")  •  Ctrl + S = Save  •  Ctrl + P = Print  •  Ctrl + F = Find Exception: Ctrl+V is paste, not "V for verbatim". It sits next to C and X to keep the clipboard trio together under the left hand.

2. Shift — "Reverse / extend / capitalise"

Shift does three things: it capitalises a letter, it reverses a command (often), and it extends a selection.

Shift + letter = capital  •  Shift + Tab = move backwards through fields  •  Shift + Ctrl + N = sometimes "new in new window" Selection rule: hold Shift while pressing an arrow key to select text character by character; add Ctrl to select by word.

3. Alt — "Access menus / alternate action"

Alt historically opened the menu bar (Alt = "alternate access to the menu"). In modern Office, pressing Alt alone reveals KeyTips — single letters that jump to ribbon tabs.

Alt + Tab = switch between open windows  •  Alt + F4 = close active window  •  Alt + underlined letter = activate that menu item In Office: press Alt, then H for Home tab, then a letter for the command. This is the keyboard-only path through the entire ribbon.

4. Windows key (⊞) — "Operating system level"

The ⊞ Win key controls the operating system, not the application. It is the fastest route to launching applications, switching desktops, and managing windows.

⊞ + type = search & launch any app  •  ⊞ + D = show desktop  •  ⊞ + L = lock screen  •  ⊞ + E = open File Explorer  •  ⊞ + R = Run dialog  •  ⊞ + ←/→ = snap window to half screen Principle: the Windows key is the OS-level "Ctrl". It never does something inside an application — it always acts on the application itself or on the system.
The mnemonic principle. When you meet a new shortcut, ask: (1) which modifier — system, command, or menu? (2) what is the first letter of the action? The answer is usually the shortcut. Ctrl+B = Bold, Ctrl+I = Italic, Ctrl+U = Underline — across every application that supports text formatting.

E.3 Command-Line Operators (the real "shortcuts")

OperatorMeaning
>Redirect output to a file (overwrite)
>>Redirect output to a file (append)
<Redirect input from a file
|Pipe output of one command into the next
&&Run second command only if first succeeds
||Run second command only if first fails
&Run both commands regardless
*Wildcard: any characters
?Wildcard: exactly one character
Principle: in a shell, the pipe (|) is the most powerful shortcut. It turns every small command into a building block. Example: dir /b | findstr ".txt" lists only .txt files.
Exception — cmd is not case-sensitive for commands (DIR = dir = Dir), but is case-sensitive for some arguments and for filenames on case-sensitive file systems. Do not assume.
Section F

PowerShell — The Object Shell

PowerShell is not an improved Command Prompt — it is a different paradigm. Where cmd passes text between commands, PowerShell passes .NET objects. This changes everything about how you work.

F.1 The Verb-Noun Principle

Every cmdlet is Verb-Noun

PowerShell commands are called cmdlets and always follow the form Verb-Noun. This is the single most important concept. Once you know the verbs and nouns, you can guess commands you have never seen.

Get-Process  •  Set-Item  •  New-Item  •  Remove-Item  •  Start-Service  •  Stop-Service  •  Copy-Item  •  Move-Item Common verbs: Get, Set, New, Remove, Start, Stop, Restart, Copy, Move, Rename, Test, Select, Where, ForEach, Out, Write, Read, Import, Export.

F.2 Console Shortcuts (same as cmd, plus more)

ShortcutAction
TabAuto-complete cmdlet names and parameters
Ctrl + SpaceShow all completions (IntelliSense-style)
↑ / ↓Command history
F7History menu
Ctrl + RReverse-search history (like bash)
Ctrl + LClear screen
Ctrl + CAbort running command

F.3 The Pipeline — Objects, Not Text

# Get processes, filter, sort, select, export
Get-Process | Where-Object CPU -gt 100 | Sort-Object CPU -Descending |
  Select-Object -First 5 | Export-Csv top5.csv

# Because output is an OBJECT, you can access properties
(Get-Process powershell).Path

# Cmdlets for discovery
Get-Command *service*        # find all service cmdlets
Get-Help Get-Process -Full   # full documentation
Get-Member                   # inspect what an object can do

F.4 Filtering: Where vs. Where-Object

ApproachWhen to use
Where-Object { }Full script-block filtering (slow but flexible)
Where-Object Property -eq ValueSimplified syntax (PS 3.0+)
.Where({ }, 'First')Faster, method-based filtering (PS 4.0+)
PowerShell's governing principle: Verb-Noun + object pipeline. If you can name the verb and the noun, you can find the command. If you can describe the object, you can filter, sort, and export it.
Exception — execution policy. By default, PowerShell blocks unsigned scripts (Restricted policy). You must set Set-ExecutionPolicy RemoteSigned (as admin) to run local scripts. This is a security feature, not a bug. It exists because PowerShell is powerful enough to be dangerous.
Exception — aliases vs. cmdlets. dir, ls, and gci all map to Get-ChildItem. Aliases exist for familiarity but should not be used in scripts (they may not exist on other systems). Always use full cmdlet names in saved scripts.

Section H

SDKs — Software Development Kits

An SDK is not an application — it is a collection of tools (compilers, libraries, documentation, CLI utilities) that let you build for a platform. Its "shortcuts" are the CLI commands and environment variables that accelerate development.

H.1 What's Inside an SDK

  • Compiler / interpreter — turns source into runnable code
  • Libraries / APIs — pre-written code you call
  • CLI tools — build, package, deploy, test commands
  • Documentation — reference and tutorials
  • Debuggers / profilers — often shared with the IDE
  • Samples & templates — starting points

I.3 Keyboard Layout Exceptions

  • Mac vs Windows: Cmd on Mac replaces Ctrl for most application commands; Ctrl on Mac is used for terminal-style operations (e.g. Ctrl+C to abort).
  • Non-QWERTY layouts: shortcuts are bound to physical key positions, not letters. On AZERTY, Ctrl+Q may perform Ctrl+A's function.
  • International keyboards: some shortcuts require different modifier combinations (AltGr on European layouts).
  • Laptop Fn key: on compact laptops, F1–F12 may require Fn to be held. This breaks IDE debugging shortcuts unless you change the Fn lock.

I.4 When Shortcuts Fail — The Hierarchy of Fallbacks

  1. Try the menu. If the shortcut doesn't work, the command still exists somewhere in a menu or ribbon. Find it, and the shortcut is usually shown beside it.
  2. Open the Command Palette / Action Search. VS Code (Ctrl+Shift+P), JetBrains (Shift+Shift), Visual Studio (Ctrl+T).
  3. Check the app's Keyboard Shortcuts settings. Almost every app has a searchable list. Search for the action name.
  4. Use the terminal. If the GUI blocks you, the CLI version of the same tool almost always exists (e.g. npm, dotnet, git).
  5. Rebind it. If a shortcut conflicts with a system binding, most apps let you change it.
The master principle: shortcuts exist to reduce the distance between intention and action. Every app exposes the same three layers — keyboard, menu, programmatic — and the keyboard layer is always the fastest. Learn the grammar (modifier + mnemonic), and you can operate any application you meet.
