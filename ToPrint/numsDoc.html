Number Systems

Binary • Octal • Decimal • Hexadecimal — Conversions, Arithmetic & Properties
What is a number system? A number system is a consistent way of writing quantities using a fixed set of digits and a base (radix). The base tells you how many distinct digit symbols exist and how much each position is worth. Digital systems use base 2 (binary) because circuits have two reliable states — on and off. Humans prefer base 10. Programmers use base 8 and base 16 as compact shorthands for binary. Every system works on the same principle: each position is worth the base raised to a power.
Section A

The Four Systems, Explained

1. Decimal (Base 10)

The everyday system. Ten digit symbols — 0–9 — and each position is worth ten times the one to its right. It is a positional system: the value of a digit depends on where it sits.

N = dn…d1d0 = Σ di × 10i Example: 4 7 2 = 4×102 + 7×101 + 2×100 = 400 + 70 + 2.

2. Binary (Base 2)

Only two digit symbols — 0 and 1 — which map directly onto a circuit being off or on. Every position doubles in value from right to left: 1, 2, 4, 8, 16, 32… This is the native language of all digital hardware.

N2 = Σ bi × 2i where bi ∈ {0, 1} Example: 1 0 1 12 = 8 + 0 + 2 + 1 = 1110.

3. Octal (Base 8)

Eight digit symbols — 0–7. Its great convenience is that one octal digit maps to exactly three binary digits (23 = 8), so octal is a compact shorthand for binary. Used historically in early computing and in Unix file permissions.

N8 = Σ oi × 8i where oi ∈ {0…7} Example: 7 5 38 = 7×64 + 5×8 + 3 = 448 + 40 + 3 = 49110.

4. Hexadecimal (Base 16)

Sixteen digit symbols. Because we only have ten numeral glyphs, hex borrows letters: A=10, B=11, C=12, D=13, E=14, F=15. Its key convenience is that one hex digit maps to exactly four binary digits (24 = 16), making it the standard compact notation for memory addresses, colour codes, and machine code.

N16 = Σ hi × 16i where hi ∈ {0…9, A…F} Example: 2 A F16 = 2×256 + 10×16 + 15 = 512 + 160 + 15 = 68710.

5. Why Bases Are Grouped: 2 / 8 / 16

Octal and hexadecimal are not arbitrary — they are powers of two. Three binary bits group perfectly into one octal digit; four binary bits group perfectly into one hex digit. This means converting between binary and octal/hex is pure regrouping, never arithmetic.

23 = 8 • 24 = 16 Example: 1101 01102 → 1101|0110 → D616 (one hex digit per 4-bit group).
