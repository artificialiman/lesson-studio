Practice Worksheet (Set A) — 30 Questions

Instructions: Answer all 30 questions. Write shortcuts using the Ctrl + X notation. For "state the principle" questions, answer in one or two full sentences.

Answer Key — Office Suite

Section A — Microsoft Word

1.Ctrl+S; Ctrl+Shift+S
2.Ctrl+E; E = cEntre (C is already Copy)
3.Ctrl+Shift+→
4.Paste as plain text; strips formatting from copied content
5.Ctrl+Enter (page); Shift+Enter (line); page break starts new page, line break stays in same paragraph
6.F7
7.Ctrl+Alt+1
8.Copies formatting; pairs with Ctrl+Shift+V to paste it elsewhere
9.Ctrl+End
10.Ctrl + first letter of the command; exceptions: Ctrl+V (paste, positional), Ctrl+E (centre, C taken)

Section B — Microsoft Excel

11.Jump to edge of data block; stops at last contiguous cell if non-empty, jumps to next non-empty if empty
12.Shift+Space (row); Ctrl+Space (column)
13.F2
14.Inside formula: cycles absolute/relative refs; outside: repeats last action
15.Alt+=
16.Ctrl+1
17.Shows formulas instead of results
18.Ctrl+letter = direct action; Alt+letter = ribbon menu navigation
19.Ctrl+Page Up / Page Down
20.Ctrl+Enter

Section C — Microsoft PowerPoint

21.Ctrl+M
22.F5 (beginning); Shift+F5 (current slide)
23.Blank screen black / white; use during Q&A to focus attention on speaker
24.Switches to pen tool (not print); presentation mode repurposes the binding
25.Alt+Shift+↑
26.Alt+F5
27.Type 7 then Enter
28.Ctrl+Shift+G (group); Ctrl+Shift+H (ungroup)
29.Send to front (z-order)
30.Speaker cannot comfortably use a mouse while talking; shortcuts keep the presentation flowing

Answer Key — Terminals, IDEs & SDKs

Section A — Command Prompt & PowerShell

1.F7 (history menu); F3 (repeat last)
2.Auto-completes file and folder names
3.copy (copy file), del (delete), dir (list), robocopy (mirror folder tree)
4.Sends output of one command as input to the next; e.g. dir /b | findstr ".txt"
5.> overwrites file; >> appends
6.Verb-Noun; e.g. Get-Process, Set-Item, New-Item
7.cmd passes text; PowerShell passes .NET objects
8.Get-Command (find cmdlets), Get-Help (documentation), Get-Member (inspect object)
9.Security policy blocking unsigned scripts; prevents malicious script execution
10.Aliases may not exist on other systems; full cmdlet names are portable

Section B — IDEs

11.VS Code: Ctrl+Shift+P; JetBrains: Shift+Shift; Visual Studio: Ctrl+T
12.F10 (over); F11 (into); Shift+F11 (out)
13.Toggle breakpoint
14.Ctrl+/
15.Go to definition
16.Find all references; F12 goes to the definition, Shift+F12 finds every use
17.F2; understands scope, so it won't rename a variable in an unrelated scope
18.Alt+Click (add cursor); Ctrl+Alt+↑/↓ (cursor above/below)
19.Ctrl+Alt+L (reformat); Alt+Enter (intentions)
20.Extensions and user customisation can override default keybindings

Section C — SDKs

21.Compiler/interpreter, libraries/APIs, CLI tools, documentation, debuggers/profilers
22.javac (compile), java (run), jar (package), javadoc (document), jps (list processes)
23.(a) npm init -y; (b) npm install <pkg>; (c) npm install -D <pkg>; (d) npm run <script>
24.dotnet new (scaffold), dotnet build (compile), dotnet run (build+run), dotnet test (test), dotnet publish (deploy)
25.adb devices (list), adb install (install APK), adb logcat (stream logs)
26.OS-level named values; SDKs use them to locate binaries and libraries regardless of working directory
27.JAVA_HOME: JDK install path; ANDROID_HOME: Android SDK install path
28.Tool that switches SDK versions per project without editing system settings
29.nvm (Node); pyenv (Python); sdkman (Java)
30.SDK provides not just a language but the full toolchain — build, test, package, deploy — so you work in a repeatable workflow rather than ad-hoc commands
