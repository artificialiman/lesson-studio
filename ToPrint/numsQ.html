Number Systems — Systems & Application

Properties, Digit Grouping & Real-World Use — Practice Worksheet (Set B)

Instructions: Answer all 15 questions. Where a question asks for reasoning, write in full sentences.

Section A — System Properties (Questions 1–8)

  1. How many distinct digit symbols does the hexadecimal system use? List them.
  2. Explain why binary is the natural choice for digital circuits.
  3. State the relationship between the number of bits and the number of representable values (give the formula).
  4. What is the largest decimal number representable with 4 bits?
  5. What is the largest decimal number representable with 8 bits?
  6. Explain why octal and hexadecimal are described as "shorthands for binary".
  7. Convert 1101 01102 to both octal and hexadecimal by grouping bits.
  8. Give one real-world example of hexadecimal being used in computing.

Section B — Applied Conversion (Questions 9–15)

  1. A colour is stored as #FF8000. Split it into its three hexadecimal byte values and state the decimal value of the green channel.
  2. Convert 100010 to hexadecimal.
  3. Convert 3E816 to octal (via binary).
  4. A file is 1 048 576 bytes. Express this in hexadecimal.
  5. An IPv4 address is written 192.168.1.1. State the number of bits in the address and explain how each octet relates to binary.
  6. Convert 100110102 to hexadecimal and decimal.
  7. Explain what "overflow" means in the context of fixed-width binary registers.
