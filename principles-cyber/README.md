# Principles Cyber — *Reduced to Sums & Differences*

A cybersecurity book set in the *Reduced to Sums & Differences* series, companion to the chemistry volume. Three tiers, read together — the same **why / fixed / work** division as the chemistry project (Principles · Standards · Calculation), with the third tier reconceived for a subject whose work is real-life defence, not matriculation.

Written by **Iman Christian Bassey** · Sponsored by **Tender Care Comprehensive College** · *A Granted Publication*.

A three-voice documentary — **Red** (threat / tool / vulnerability) and **Blue** (response / product / standardized response) in correspondence across real, cited recoveries, with a **Chorus** that rounds up each case. Every case subtracts to its reduction: `threat − response`, `tool − product`, `vuln − standard`. MCQs are not the point; the work is.

## Reading order
Principles I → II → III for the ideas; The Standards as the lookup you keep open; The Manual I → II → III for the work, each case paid for in a real recovery. The set's single sentence, from the shared machine of 1965 to the agent of 2026: **separation and proof, maintained.**

## Note on the AI/ARTEX material
Written defensively, from public reporting (FBI/IC3, Check Point, SentinelOne, Sophos). It describes the threat to resist it — no operational attack guidance. Live-threat figures reflect reporting through mid-November 2026 and describe reach, not confirmed counts; re-verify against current advisories.
