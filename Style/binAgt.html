Binary Operations

Properties Explained • 20 Practice Questions • Full Worked Solutions
What is a binary operation? A binary operation is a rule that takes two elements from a set and combines them to produce one result. The result must also belong to the set for the operation to be well-defined on that set. When you see a symbol like a ∗ b = a + b − 3, the star is being defined as a new operation. Read every question as: "apply the given rule to the two inputs on the left, and produce the output on the right."
Section A

The Five Properties, Explained

1. Closure

A set is closed under an operation if combining any two elements of the set always produces another element that is still inside the set. Nothing escapes. Closure is the foundation every other property stands on — if the operation produces a result outside the set, the remaining properties cannot even be sensibly tested.

For all a, b ∈ S,   a ∗ b ∈ S Example: The set of integers is closed under addition, because adding two integers always gives another integer. The set of positive numbers is not closed under subtraction, because 3 − 5 = −2 leaves the set.

2. Commutative

An operation is commutative if the order of the two inputs does not change the result. You can swap the two elements freely and get the same answer. Ordinary addition and multiplication are commutative; subtraction and division are not.

For all a, b ∈ S,   a ∗ b = b ∗ a Example: Addition is commutative: 4 + 7 = 7 + 4 = 11. Subtraction is not: 4 − 7 = −3 but 7 − 4 = 3.

3. Associative

An operation is associative if the grouping of three elements does not change the result. When combining three items, it does not matter whether you pair the first two first or the last two first. This is what allows us to write a + b + c without brackets.

For all a, b, c ∈ S,   (a ∗ b) ∗ c = a ∗ (b ∗ c) Example: Addition is associative: (2 + 3) + 4 = 5 + 4 = 9 and 2 + (3 + 4) = 2 + 7 = 9. Note that commutative and associative are independent — an operation can be one without the other.

4. Identity Element

An identity element is a special value that leaves every input unchanged when combined with it. It is the "do-nothing" element. For addition, the identity is 0; for multiplication, it is 1. A set can have at most one identity element for a given operation.

There exists e ∈ S such that for all a ∈ S,   a ∗ e = e ∗ a = a Example: For the operation a ∗ b = a + b − 3, the identity is e = 3, because a + 3 − 3 = a.

5. Inverse Element

An inverse of an element a is another element that combines with a to produce the identity. It is the element that "undoes" a. Every element must have an inverse for the set to satisfy this property. Under addition, the inverse of 5 is −5, because 5 + (−5) = 0.

For each a ∈ S, there exists a−1 ∈ S such that a ∗ a−1 = a−1 ∗ a = e Example: For a ∗ b = a + b − 3 with identity e = 3, the inverse of a is 6 − a, because a + (6 − a) − 3 = 3.

6. Distributive (Bonus Property)

An operation ∗ is distributive over another operation ◊ if you can "spread" the first operation across the second. This is the property behind expanding brackets, like 2(3 + 4) = 2(3) + 2(4). Distributivity always relates two operations, never just one.

For all a, b, c ∈ S,   a ∗ (b ◊ c) = (a ∗ b) ◊ (a ∗ c) Example: Multiplication distributes over addition: 3 × (2 + 5) = 3(2) + 3(5) = 6 + 15 = 21. Addition does not distribute over multiplication: 3 + (2 × 5) ≠ (3 + 2) × (3 + 5).

Practice Questions

Questions 1–20
  1. A binary operation is defined on the set of real numbers by a ∗ b = a + b + 5. Find 3 ∗ 4.
  2. For the operation a ∗ b = 2a − b, find 5 ∗ 3.
  3. Given x ∗ y = xy + x + y, find 2 ∗ 5.
  4. An operation is defined by p ∗ q = p + q2. Find 7 ∗ 9.
  5. For a ∗ b = a2 + b2, find 3 ∗ 4.
  6. The operation ∗ is defined by a ∗ b = a + b − 7. Find the identity element.
  7. For the operation a ∗ b = 3ab, find the identity element.
  8. Given m ∗ n = m + n + mn, find the identity element.
  9. For a ∗ b = a + b − 4, find the inverse of 7.
  10. For a ∗ b = 2a + 2b − 3, find the inverse of 5.
  11. Determine whether the operation a ∗ b = a + 2b is commutative. Justify your answer with a counter-example.
  12. Determine whether the operation a ∗ b = ab + 3 is commutative.
  13. Test whether a ∗ b = 2ab is associative.
  14. Test whether a ∗ b = a + b − 2 is associative.
  15. The operation a ∗ b = a + b − k has an identity element equal to 4. Find k.
  16. Given x ∗ y = 2x + 2y + c, and the identity element is −2, find the value of c.
  17. For a ∗ b = a + b − 6, solve for x if x ∗ 4 = 8.
  18. For a ∗ b = ab − a − b, solve for x if x ∗ 3 = 7.
  19. A binary operation is defined by a ∗ b = a + bab for a, b ≠ 0. Find 2 ∗ 6.
  20. The operation ∗ on the set {1, 2, 3, …} is defined by a ∗ b = a + b + ab. Find (1 ∗ 2) ∗ 3 and comment on whether the set is closed under this operation.
