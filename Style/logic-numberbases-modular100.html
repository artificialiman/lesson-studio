BLOCK 1 · Q1–Q10 Logical Reasoning — Statements & Connectives (Flow)
Q 01Logic
Which of the following is a simple statement?
(A) Either Amaka passed or she failed. (B) Lagos is the largest city in Nigeria. (C) If it rains, the ground gets wet. (D) Mathematics is easy and interesting.
Recall: A simple (atomic) statement has no connective — it expresses one complete thought that is either true or false. Option B: one subject (Lagos), one predicate — no connective. This is a simple statement. ✓ Option A uses "or" (disjunction). Option C uses "if…then" (implication). Option D uses "and" (conjunction).
Answer: B
Q 02Logic
The symbol \(\land\) represents which logical connective?
(A) Disjunction ("or") (B) Negation ("not") (C) Conjunction ("and") (D) Implication ("if…then")
Standard symbols: \(\land\) — conjunction (AND) \(\lor\) — disjunction (OR) \(\lnot\) or \(\sim\) — negation (NOT) \(\Rightarrow\) or \(\rightarrow\) — implication (IF…THEN) \(\Leftrightarrow\) or \(\leftrightarrow\) — biconditional (IF AND ONLY IF)
Answer: C — Conjunction
Q 03Logic
Let \(p\) = "Bola studies hard" and \(q\) = "Bola passes the exam." Write the statement \(p \land q\) in words.
(A) If Bola studies hard, then Bola passes the exam. (B) Bola studies hard and Bola passes the exam. (C) Bola studies hard or Bola passes the exam. (D) Bola does not study hard.
Recall: \(p \land q\) joins both components with "and." \(p \land q\) = "Bola studies hard and Bola passes the exam." ✓
Answer: B
Q 04Logic
If \(p\) is TRUE and \(q\) is FALSE, what is the truth value of \(p \land q\)?
(A) TRUE (B) FALSE (C) Undefined (D) Depends on context
Conjunction rule: \(p \land q\) is TRUE only when both \(p\) and \(q\) are TRUE. Here \(p = T,\ q = F\), so \(p \land q = F\). Memory aid: AND is like multiplication — one zero makes the product zero.
Answer: B — FALSE
Q 05Logic
If \(p\) is FALSE and \(q\) is FALSE, what is the truth value of \(p \lor q\)?
(A) TRUE (B) FALSE (C) TRUE only if \(p = q\) (D) Cannot be determined
Disjunction rule: \(p \lor q\) is FALSE only when both components are FALSE. \(p = F,\ q = F \Rightarrow p \lor q = F\). In all other cases (T,F), (F,T), (T,T) → the disjunction is TRUE.
Answer: B — FALSE
Q 06Logic
What is the negation of the statement: "All students passed the test"?
(A) No student passed the test. (B) Some students did not pass the test. (C) All students failed the test. (D) No student failed the test.
Negation of "All A are B" = "Some A are NOT B" (at least one exception exists). The negation does not say "none passed" — that is too strong. It says the universal claim is broken: some students did not pass. ✓
Answer: B — Some students did not pass.
Q 07Logic
The statement "Emeka is tall or Emeka plays football" is TRUE. Emeka is known to NOT play football. What can you conclude?
(A) Emeka is not tall. (B) Emeka is tall. (C) Nothing can be concluded. (D) Both components must be false.
Disjunctive syllogism: \(p \lor q\) is TRUE, and \(q\) is FALSE \(\Rightarrow\) \(p\) must be TRUE. Let \(p\) = "Emeka is tall", \(q\) = "Emeka plays football." \(p \lor q = T\) and \(q = F \Rightarrow p = T\). Emeka is tall. ✓
Answer: B — Emeka is tall.
Q 08Logic
Which of the following sentences is NOT a statement (i.e., cannot have a definite truth value)?
(A) \(5 + 3 = 9\) (B) Abuja is the capital of Nigeria. (C) Please close the door. (D) January has 31 days.
A statement must be either TRUE or FALSE — not both, not neither. Commands, questions, and exclamations are not statements. "Please close the door" is a command — it has no truth value. ✓ Option A is a (false) statement. Options B and D are (true) statements.
Answer: C — A command has no truth value.
Q 09Logic
Using \(p\): "The sky is blue" (TRUE) and \(q\): "Grass is red" (FALSE), evaluate \(\lnot p \lor q\).
(A) TRUE (B) FALSE (C) TRUE and FALSE simultaneously (D) Depends on the weather
Step by step: 1. \(\lnot p = \lnot T = F\) 2. \(q = F\) 3. \(\lnot p \lor q = F \lor F = F\) Disjunction is only FALSE when both operands are FALSE — which is the case here.
Answer: B — FALSE
Q 10Logic
The compound statement \(\lnot(p \land q)\) is logically equivalent to which of the following (De Morgan's Law)?
(A) \(\lnot p \land \lnot q\) (B) \(\lnot p \lor \lnot q\) (C) \(p \lor q\) (D) \(p \land q\)
De Morgan's First Law: \(\lnot(p \land q) \equiv \lnot p \lor \lnot q\) When you negate a conjunction, the AND becomes OR and each component is negated. Similarly: \(\lnot(p \lor q) \equiv \lnot p \land \lnot q\). Verify with \(p=T, q=F\): LHS = \(\lnot(T \land F) = \lnot F = T\). RHS = \(F \lor T = T\). ✓
Answer: B — \(\lnot p \lor \lnot q\)
BLOCK 2 · Q11–Q20 Truth Tables — Reading & Building
Q 11Logic
Complete the truth table for \(p \land q\). Which row gives a TRUE result?
\(p\)\(q\)\(p \land q\)
TT?
TF?
FT?
FF?
(A) Row 1 only (T, T) (B) Rows 1 and 2 (C) Rows 1, 2, and 3 (D) All four rows
Conjunction is TRUE only when BOTH operands are TRUE. Row 1: T ∧ T = T ✓ Row 2: T ∧ F = F Row 3: F ∧ T = F Row 4: F ∧ F = F
Answer: A — Row 1 only
Q 12Logic
In how many rows of a two-variable truth table is \(p \lor q\) FALSE?
(A) 0 rows (B) 1 row (C) 2 rows (D) 4 rows
Disjunction is FALSE only when BOTH operands are FALSE. Only the combination (F, F) gives a FALSE disjunction — that is exactly 1 row. A two-variable truth table has \(2^2 = 4\) rows total.
Answer: B — 1 row (when both p and q are F)
Q 13Logic
How many rows does a truth table with three variables \(p,\ q,\ r\) have?
(A) 3 (B) 6 (C) 8 (D) 9
Formula: A truth table with \(n\) variables has \(2^n\) rows. \(n = 3 \Rightarrow 2^3 = 8\) rows. 1 variable → 2 rows; 2 variables → 4 rows; 3 variables → 8 rows; 4 → 16, etc.
Answer: C — 8 rows
Q 14Logic
Evaluate \(\lnot p \land q\) when \(p = F\) and \(q = T\).
(A) TRUE (B) FALSE (C) Undefined (D) Same as \(p \land q\)
Step 1: \(\lnot p = \lnot F = T\) Step 2: \(\lnot p \land q = T \land T = T\) Key: Evaluate negation before the conjunction (negation has highest precedence).
Answer: A — TRUE
Q 15Logic
Which of the following is a tautology — a statement that is TRUE in every row of its truth table?
(A) \(p \land \lnot p\) (B) \(p \lor \lnot p\) (C) \(p \land q\) (D) \(p \lor q\)
Tautology = always TRUE. Contradiction = always FALSE. \(p \lor \lnot p\): either \(p\) is true (first disjunct is T) or \(p\) is false (second disjunct is T). Always TRUE. ✓ \(p \land \lnot p\): always FALSE (contradiction — Law of Non-Contradiction). \(p \land q\) and \(p \lor q\) have mixed truth values — not tautologies.
Answer: B — \(p \lor \lnot p\) (tautology)
Q 16Logic
Determine the truth value of \((p \land q) \lor \lnot p\) when \(p = T,\ q = F\).
(A) TRUE (B) FALSE (C) Same as \(q\) (D) Cannot be evaluated
Step 1: \(p \land q = T \land F = F\) Step 2: \(\lnot p = \lnot T = F\) Step 3: \(F \lor F = F\) Order of operations: negation first, then conjunction, then disjunction.
Answer: B — FALSE
Q 17Logic
What is the truth value of \(\lnot(p \lor q)\) when \(p = F\) and \(q = F\)?
(A) TRUE (B) FALSE (C) Same as \(p \lor q\) (D) Same as \(\lnot p\)
Step 1: \(p \lor q = F \lor F = F\) Step 2: \(\lnot(F) = T\) The only time \(p \lor q = F\) is when both are FALSE, making its negation TRUE.
Answer: A — TRUE
Q 18Logic
Using the truth table below, identify the column that represents \(\lnot p \lor q\):
\(p\)\(q\)Col ACol BCol C
TTTFT
TFFFT
FTTTT
FFFTF
(A) Column A (B) Column B (C) Column C (D) None of the above
Build \(\lnot p \lor q\) row by row: Row 1: \(\lnot T \lor T = F \lor T = T\) Row 2: \(\lnot T \lor F = F \lor F = F\) Row 3: \(\lnot F \lor T = T \lor T = T\) Row 4: \(\lnot F \lor F = T \lor F = T\) Results: T, F, T, T — matches Column A. ✓
Answer: A — Column A
Q 19Logic
A statement is a contradiction if it is:
(A) TRUE in every possible case (B) FALSE in every possible case (C) TRUE in some cases and FALSE in others (D) Neither TRUE nor FALSE
Tautology: TRUE in every row — e.g. \(p \lor \lnot p\). Contradiction: FALSE in every row — e.g. \(p \land \lnot p\). Contingency: TRUE in some rows, FALSE in others — e.g. \(p \land q\).
Answer: B — FALSE in every possible case
Q 20Logic
Two statements are logically equivalent (\(\equiv\)) if:
(A) They have the same number of variables. (B) Their truth tables have identical final columns for all rows. (C) They use the same connective. (D) One is the negation of the other.
Logical equivalence means the two statements have exactly the same truth value in every possible row. Example: \(\lnot(p \land q) \equiv \lnot p \lor \lnot q\) — their truth table columns are identical in all 4 rows. This is tested by building both columns and confirming they match row for row.
Answer: B — Identical truth table columns
BLOCK 3 · Q21–Q30 Implication, Contrapositive & Biconditional
Q 21Logic
The implication \(p \Rightarrow q\) is FALSE only when:
(A) \(p\) is TRUE and \(q\) is FALSE. (B) \(p\) is FALSE and \(q\) is TRUE. (C) Both \(p\) and \(q\) are FALSE. (D) Both \(p\) and \(q\) are TRUE.
Implication truth table:
\(p\)\(q\)\(p \Rightarrow q\)
TTT
TFF
FTT
FFT
The implication is FALSE only when the hypothesis is TRUE but the conclusion is FALSE — "a true premise led to a false conclusion" is the one thing a valid implication cannot allow. When \(p\) is FALSE, the implication is vacuously TRUE (a false promise can never be broken).
Answer: A — \(p\) TRUE and \(q\) FALSE
Q 22Logic
Given \(p \Rightarrow q\), the contrapositive is:
(A) \(q \Rightarrow p\) (converse) (B) \(\lnot p \Rightarrow \lnot q\) (inverse) (C) \(\lnot q \Rightarrow \lnot p\) (contrapositive) (D) \(\lnot p \Rightarrow q\)
Three related forms of \(p \Rightarrow q\): Converse: \(q \Rightarrow p\) Inverse: \(\lnot p \Rightarrow \lnot q\) Contrapositive: \(\lnot q \Rightarrow \lnot p\) — logically equivalent to the original! ✓ Note: only the contrapositive is always equivalent to the original implication.
Answer: C — \(\lnot q \Rightarrow \lnot p\)
Q 23Logic
Write the contrapositive of: "If a number is even, then it is divisible by 2."
(A) If a number is divisible by 2, then it is even. (B) If a number is not even, then it is not divisible by 2. (C) If a number is not divisible by 2, then it is not even. (D) A number is even and divisible by 2.
Let \(p\) = "the number is even," \(q\) = "it is divisible by 2." Contrapositive: \(\lnot q \Rightarrow \lnot p\) = "If a number is NOT divisible by 2, then it is NOT even." ✓ Option A is the converse (\(q \Rightarrow p\)). Option B is the inverse (\(\lnot p \Rightarrow \lnot q\)).
Answer: C
Q 24Logic
The biconditional \(p \Leftrightarrow q\) is TRUE when:
(A) \(p\) is TRUE only. (B) \(p\) and \(q\) have the same truth value (both TRUE or both FALSE). (C) \(p\) is FALSE and \(q\) is TRUE. (D) At least one of them is TRUE.
Biconditional truth table:
\(p\)\(q\)\(p \Leftrightarrow q\)
TTT
TFF
FTF
FFT
"If and only if" — TRUE precisely when both sides agree.
Answer: B — Same truth value for both
Q 25Logic
Evaluate \(p \Rightarrow q\) where \(p = F\) and \(q = F\).
(A) FALSE — both inputs are false. (B) TRUE — a false hypothesis makes the implication vacuously true. (C) Undefined. (D) Depends on the context of \(p\) and \(q\).
From the implication truth table: when \(p = F\), \(p \Rightarrow q\) is always TRUE regardless of \(q\). Intuition: "If I fail (false hypothesis), then I will cry." Even if I don't cry, you cannot call this statement a lie — I never failed! This is called vacuous truth.
Answer: B — TRUE (vacuous truth)
Q 26Logic
Which pair of statements is logically equivalent?
(A) \(p \Rightarrow q\) and \(q \Rightarrow p\) (B) \(p \Rightarrow q\) and \(\lnot q \Rightarrow \lnot p\) (C) \(p \Rightarrow q\) and \(\lnot p \Rightarrow \lnot q\) (D) \(p \Rightarrow q\) and \(\lnot p \lor q\) — both of these
Check all pairs: A: Original vs. Converse — NOT equivalent. B: Original vs. Contrapositive — EQUIVALENT. ✓ C: Original vs. Inverse — NOT equivalent (equivalent to converse). D: \(p \Rightarrow q \equiv \lnot p \lor q\) is also true — but option B is the standard SS1 answer.
Answer: B — Original ≡ Contrapositive
Q 27Logic
Given the argument:
Premise 1: \(p \Rightarrow q\)
Premise 2: \(p\) is TRUE
Conclusion: \(q\) is TRUE
This is the law of:
(A) De Morgan (B) Modus Ponens (Law of Detachment) (C) Modus Tollens (D) Disjunctive Syllogism
Modus Ponens: "If \(p \Rightarrow q\) and \(p\) is true, then \(q\) must be true." Modus Tollens: If \(p \Rightarrow q\) and \(q\) is FALSE, then \(p\) is FALSE. Disjunctive Syllogism: If \(p \lor q\) and \(\lnot p\), then \(q\). These are the three core valid argument forms tested at SS1–SS2 level.
Answer: B — Modus Ponens
Q 28Logic
Which of the following is the correct symbolic form of: "It is not the case that Chidi passed and scored an A"?
(A) \(\lnot p \land \lnot q\) (B) \(\lnot(p \land q)\) (C) \(\lnot p \lor q\) (D) \(p \land \lnot q\)
Let \(p\) = "Chidi passed", \(q\) = "Chidi scored an A." "Chidi passed AND scored an A" = \(p \land q\). "It is NOT the case that..." = negate the whole thing = \(\lnot(p \land q)\). ✓ By De Morgan: this equals \(\lnot p \lor \lnot q\), which is different from option A.
Answer: B — \(\lnot(p \land q)\)
Q 29Logic
The statement "A quadrilateral is a square if and only if it has four equal sides and four right angles" uses which connective?
(A) Conjunction (B) Disjunction (C) Biconditional (D) Implication
"If and only if" (iff) = biconditional (\(\Leftrightarrow\)). Biconditionals express definitions — "A is B if and only if A has exactly the properties of B." This is the strongest form: both directions hold simultaneously.
Answer: C — Biconditional
Q 30Logic
Evaluate \(p \Leftrightarrow q\) given \(p = T,\ q = F\).
(A) TRUE (B) FALSE (C) TRUE only if \(p \Rightarrow q\) (D) Same as \(p \land q\)
Biconditional is TRUE only when both sides agree in truth value. Here \(p = T\) and \(q = F\) — they disagree, so \(p \Leftrightarrow q = F\).
Answer: B — FALSE
BLOCK 4 · Q31–Q40 Number Bases — Conversions (Flow)
Q 31Bases
Convert \(1011_2\) to base 10.
(A) 9(B) 11 (C) 13(D) 10
Method: Multiply each digit by \(2^{\text{position}}\), summing from right (position 0).
Position: 3 2 1 0 Digit: 1 0 1 1 Value: 1×8 + 0×4 + 1×2 + 1×1 = 8 + 0 + 2 + 1 = 11
Answer: B — 11
Q 32Bases
Convert \(25_{10}\) to base 2.
(A) \(10011_2\)(B) \(11001_2\) (C) \(10110_2\)(D) \(11010_2\)
Method: Repeated division by 2, read remainders bottom to top.
25 ÷ 2 = 12 remainder 1 ↑ LSB 12 ÷ 2 = 6 remainder 0 6 ÷ 2 = 3 remainder 0 3 ÷ 2 = 1 remainder 1 1 ÷ 2 = 0 remainder 1 ↑ MSB Read upward: 1 1 0 0 1 → 11001₂
Verify: \(16+8+0+0+1 = 25\). ✓
Answer: B — \(11001_2\)
Q 33Bases
Convert \(101_2\) to base 10.
(A) 4(B) 5 (C) 6(D) 3
1×4 + 0×2 + 1×1 = 4 + 0 + 1 = 5
Answer: B — 5
Q 34Bases
Convert \(47_{10}\) to base 8 (octal).
(A) \(57_8\)(B) \(47_8\) (C) \(55_8\)(D) \(67_8\)
47 ÷ 8 = 5 remainder 7 ↑ LSB 5 ÷ 8 = 0 remainder 5 ↑ MSB Read upward: 5 7 → 57₈
Verify: \(5 \times 8 + 7 = 40 + 7 = 47_{10}\). ✓
Answer: A — \(57_8\)
Q 35Bases
Convert \(2D_{16}\) to base 10. (Recall: D\(_{16}\) = 13\(_{10}\))
(A) 29(B) 45 (C) 32(D) 41
2D₁₆: Position: 1 0 Digit: 2 D(=13) Value: 2×16 + 13×1 = 32 + 13 = 45
Answer: B — 45
Q 36Bases
Convert \(100_{10}\) to base 16 (hexadecimal).
(A) \(\text{6}4_{16}\)(B) \(\text{64}_{16}\) (C) \(\text{A0}_{16}\)(D) \(\text{100}_{16}\)
100 ÷ 16 = 6 remainder 4 ↑ LSB 6 ÷ 16 = 0 remainder 6 ↑ MSB Read upward: 6 4 → 64₁₆
Verify: \(6 \times 16 + 4 = 96 + 4 = 100_{10}\). ✓
Answer: B — \(64_{16}\)
Q 37Bases
Convert \(1101_2\) to base 8 (octal). The best method is to group binary digits in threes from the right.
(A) \(15_8\)(B) \(17_8\) (C) \(13_8\)(D) \(25_8\)
Group in 3s from the right:
1101₂ → pad left: 001 101 Group: 001 101 Value: 1 5 Result: 15₈
Verify: \(1 \times 8 + 5 = 13_{10}\). Check \(1101_2 = 8+4+1 = 13_{10}\). ✓
Answer: A — \(15_8\)
Q 38Bases
Convert \(B3_{16}\) to base 10. (B\(_{16}\) = 11\(_{10}\))
(A) 163(B) 179 (C) 116(D) 203
B3₁₆: B = 11, 3 = 3 11 × 16 + 3 × 1 = 176 + 3 = 179
Answer: B — 179
Q 39Bases
What is the value of \(111111_2\) in base 10?
(A) 62(B) 63 (C) 64(D) 61
111111₂ = 32+16+8+4+2+1 = 63
Shortcut: A string of \(n\) ones in binary = \(2^n - 1\). Here \(n=6 \Rightarrow 2^6 - 1 = 64 - 1 = 63\). ✓
Answer: B — 63
Q 40Bases
Convert \(256_{10}\) to base 2. How many binary digits (bits) does the result have?
(A) 8 bits(B) 9 bits (C) 7 bits(D) 10 bits
256 = 2⁸ → binary: 1 0000 0000 That is 1 followed by eight 0s → 9 bits total.
Key: \(2^n\) in binary is a 1 followed by \(n\) zeros, giving \(n+1\) bits. \(256 = 2^8 \Rightarrow 9\) bits.
Answer: B — 9 bits
BLOCK 5 · Q41–Q50 Arithmetic in Other Bases — Addition, Subtraction & Multiplication
Q 41Bases
Evaluate \(1011_2 + 110_2\).
(A) \(10001_2\)(B) \(10111_2\) (C) \(1101_2\)(D) \(10011_2\)
Binary addition rules: \(0+0=0\); \(1+0=1\); \(1+1=10\) (write 0, carry 1); \(1+1+1=11\) (write 1, carry 1).
1 0 1 1 + 1 1 0 --------- 1 0 0 0 1 ← 10001₂
Column by column from right: 1+0=1; 1+1=10 (0, carry1); 0+1+1=10 (0, carry1); 1+0+1=10 (0, carry1); carry 1 → final MSB. Check: \(11+6=17=16+1=10001_2\). ✓
Answer: A — \(10001_2\)
Q 42Bases
Evaluate \(1100_2 - 0101_2\).
(A) \(0111_2\)(B) \(1001_2\) (C) \(0011_2\)(D) \(1000_2\)
Binary subtraction rules: \(0-0=0\); \(1-0=1\); \(1-1=0\); \(0-1\) = borrow, giving \(10-1=1\) (and reduce next column by 1).
1 1 0 0 - 0 1 0 1 --------- 0 1 1 1 ← 0111₂
Check: \(12 - 5 = 7 = 0111_2\). ✓
Answer: A — \(0111_2\)
Q 43Bases
Evaluate \(23_8 + 15_8\) in base 8.
(A) \(38_8\)(B) \(40_8\) (C) \(36_8\)(D) \(48_8\)
Octal addition: carry occurs when the column sum ≥ 8.
2 3₈ + 1 5₈ ------ Column 0 (units): 3 + 5 = 8 → 8 ÷ 8 = 1 rem 0 → write 0, carry 1 Column 1 (eights): 2 + 1 + 1 (carry) = 4 → write 4 Result: 4 0₈ → 40₈
Check: \(19 + 13 = 32 = 4 \times 8 + 0 = 40_8\). ✓
Answer: B — \(40_8\)
Q 44Bases
Find the result of \(101_2 \times 11_2\).
(A) \(1011_2\)(B) \(1111_2\) (C) \(10011_2\)(D) \(1001_2\)
Binary multiplication: same as long multiplication — multiply by each bit then shift left.
1 0 1 (= 5) × 1 1 (= 3) ------- 1 0 1 (101 × 1, shift 0) + 1 0 1 0 (101 × 1, shift 1) --------- 1 1 1 1 (= 15)
Check: \(5 \times 3 = 15 = 8+4+2+1 = 1111_2\). ✓
Answer: B — \(1111_2\)
Q 45Bases
Evaluate \(312_4 + 231_4\) in base 4.
(A) \(1203_4\)(B) \(543_4\) (C) \(1213_4\)(D) \(1023_4\)
Base-4 addition: carry when column sum ≥ 4. Digits in base 4 are 0, 1, 2, 3 only.
3 1 2₄ + 2 3 1₄ -------- Col 0: 2+1 = 3 → write 3, carry 0 Col 1: 1+3 = 4 → 4÷4 = 1 rem 0 → write 0, carry 1 Col 2: 3+2+1(carry) = 6 → 6÷4 = 1 rem 2 → write 2, carry 1 Col 3: carry 1 → write 1 Result: 1 2 0 3₄ → 1203₄
Check: \(3(16)+1(4)+2 = 54\); \(2(16)+3(4)+1=45\); \(54+45=99\). \(1203_4 = 64+2(4)+3 = 64+32+3 = 99\). ✓
Answer: A — \(1203_4\)
Q 46Bases
Which of the following numbers is invalid in base 3?
(A) \(2102_3\)(B) \(1021_3\) (C) \(2003_3\)(D) \(1200_3\)
Rule: In base \(b\), valid digits are \(0, 1, 2, \ldots, b-1\). In base 3: valid digits are 0, 1, 2 only. Option C: \(2003_3\) contains the digit 3, which is not a valid base-3 digit. ✓
Answer: C — \(2003_3\) (digit 3 is invalid in base 3)
Q 47Bases
Convert \(110.11_2\) to base 10. (Note the binary point — treat fractional bits.)
(A) \(6.5\)(B) \(6.75\) (C) \(7.5\)(D) \(5.75\)
Fractional binary: positions to the right of the point are \(2^{-1}, 2^{-2}, \ldots\)
Integer part: 1 1 0 → 4+2+0 = 6 Fractional part: .1 1 → ½ + ¼ = 0.5 + 0.25 = 0.75 Total: 6 + 0.75 = 6.75
Answer: B — 6.75
Q 48Bases
Evaluate: \(1000_2 - 1_2\).
(A) \(111_2\)(B) \(0111_2\) (C) \(1001_2\)(D) \(0110_2\)
1000₂ = 8, subtract 1 → 7 = 0111₂
Pattern to know: subtracting 1 from a power of 2 in binary flips all trailing zeros to ones and the leading 1 to 0. \(1000 - 1 = 0111\).
Answer: B — \(0111_2\)
Q 49Bases
The hexadecimal number \(\text{FF}_{16}\) equals which base-10 value?
(A) 240(B) 255 (C) 256(D) 160
FF₁₆: F = 15 15×16 + 15×1 = 240 + 15 = 255
Shortcut: \(\text{FF}_{16} = 2^8 - 1 = 256 - 1 = 255\). (Two hex digits hold \(8\) bits; all 1s = \(2^8 -1\).)
Answer: B — 255
Q 50Bases
A number in base 5 is written as \(304_5\). What is its value in base 10?
(A) 79(B) 69 (C) 85(D) 89
3×5² + 0×5¹ + 4×5⁰ = 3×25 + 0×5 + 4×1 = 75 + 0 + 4 = 79
Answer: A — 79
BLOCK 6 · Q51–Q60 Modular Arithmetic — Clock Arithmetic & Modular Tables (Flow)
Q 51Mod
What is \(17 \pmod{5}\)?
(A) 1(B) 2 (C) 3(D) 4
Definition: \(a \pmod{m}\) is the remainder when \(a\) is divided by \(m\). \(17 \div 5 = 3\) remainder \(2\). \(5 \times 3 = 15;\quad 17 - 15 = 2.\) So \(17 \equiv 2 \pmod{5}\).
Answer: B — 2
Q 52Mod
A clock shows 10:00. What time will it show in 15 hours?
(A) 2:00(B) 1:00 (C) 3:00(D) 25:00
\(10 + 15 = 25\) \(25 \pmod{12} = 25 - 24 = 1\) (since \(12 \times 2 = 24\)). The clock will show 1:00. Clock arithmetic is always mod 12.
Answer: B — 1:00
Q 53Mod
What is \((-3) \pmod{7}\)?
(A) \(-3\)(B) 3 (C) 4(D) 7
