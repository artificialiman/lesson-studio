Evaluating & Domain Restrictions

Questions 1–10
  1. Given f(x) = 5x − 3, find f(6).
  2. Given g(x) = x2 − 4x, find g(−2).
  3. State the domain of f(x) = 1x − 5. Write your answer using the “not equal to” symbol.
  4. State the domain of f(x) = 3x + 4.
  5. Find the range of f(x) = x2 + 3 for x ∈ ℝ.
  6. Find the range of f(x) = x2 − 7 for x ∈ ℝ.
  7. State the domain of h(x) = x − 6. Write your answer using the “greater than or equal to” symbol.
  8. State the domain of h(x) = x + 7.
  9. Given f(x) = x − 1x + 2, find f(3).
  10. Given f(x) = 2x + 3x − 1, find f(2) and state the value of x that must be excluded from the domain.
Section B

Composite Functions & Substitution

Questions 11–20
  1. Given f(x) = 3x + 1 and g(x) = x2, find (f ∘ g)(x).
  2. Given f(x) = 2x − 3 and g(x) = x2, find (f ∘ g)(x).
  3. Given f(x) = x + 5 and g(x) = 2x, find (g ∘ f)(3).
  4. Given f(x) = x − 2 and g(x) = 4x, find (g ∘ f)(5).

  6. If f(x) = 3x and g(x) = x − 4, find f(g(6)).
  7. Given f(x) = x2 + 2, find f(a + 3) in simplest form.
  8. Given f(x) = x2 − 3, find f(a − 2) in simplest form.
  9. Given f(x) = 2x + 1 and g(x) = 1x, find (f ∘ g)(x), stating any restriction on x.
  10. Given f(x) = x2 − 1 and g(x) = x, find (f ∘ g)(x), stating any restriction on x.
