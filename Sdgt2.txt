WEEK 1: REVIEW OF SS1 DIGITAL FOUNDATIONS
TOPIC: A COMPREHENSIVE REVIEW OF KEY SS1 CONCEPTS
INTRODUCTION: This week serves as a critical foundation for the advanced topics in SS2.
We will conduct a deep review of the fundamental principles of digital technology, ensuring all
students have the requisite knowledge to proceed. This is not a superficial overview; it is an indepth
re-examination of core concepts.
1: CORE COMPONENTS OF A COMPUTER SYSTEM
 HARDWARE: The tangible, physical components of the system.
o INPUT DEVICES: (e.g., Keyboard, Mouse, Scanner, Microphone). These are
the conduits for human-to-computer interaction, translating analog actions into
digital signals.
o OUTPUT DEVICES: (e.g., Monitor, Printer, Speakers). These translate digital
signals back into human-readable (visual, auditory, or physical) formats.
o CENTRAL PROCESSING UNIT (CPU): The "brain." It executes instructions.
Its performance is measured in Gigahertz (GHz), representing billions of cycles
per second. It consists of the Arithmetic Logic Unit (ALU) for calculations and
the Control Unit (CU) for managing instructions.
o MEMORY (PRIMARY STORAGE):
 RAM (RANDOM ACCESS MEMORY): Volatile (temporary) memory
used to hold data and applications currently in use. It is extremely fast and
essential for multitasking.
 ROM (READ-ONLY MEMORY): Non-volatile (permanent) memory
that holds the BIOS (Basic Input/Output System) or UEFI, which is the
firmware that boots the computer.
o STORAGE (SECONDARY STORAGE):
2
 HDD (HARD DISK DRIVE): Non-volatile magnetic storage. Slower,
but cheaper with high capacity.
 SSD (SOLID-STATE DRIVE): Non-volatile flash storage. Significantly
faster than HDDs, more durable, but more expensive.
 SOFTWARE: The intangible set of instructions (programs) that tell the hardware what
to do.
o SYSTEM SOFTWARE (OPERATING SYSTEM): The master program that
manages all other software and hardware. (e.g., Windows 11, macOS, Linux,
Android). Its functions are:
 Process management
 Memory management
 File system management
 Hardware abstraction (I/O)
 Providing a user interface (GUI/CLI)
o APPLICATION SOFTWARE: Programs designed to perform specific tasks for
the user. (e.g., MS Word, Google Chrome, Adobe Photoshop).
2: FUNDAMENTALS OF DATA REPRESENTATION
 THE BINARY SYSTEM: The native language of all digital computers. It uses only two
digits: 0 (OFF) and 1 (ON).
 BIT: A single binary digit (a 0 or 1).
 BYTE: A group of 8 bits. A byte is the standard unit of measurement for digital data and
can represent 256 (2^8) different values.
 CHARACTER ENCODING:
o ASCII (AMERICAN STANDARD CODE FOR INFORMATION
INTERCHANGE): An early 7-bit (later 8-bit) standard to map keyboard
characters (A, b, !, 3) to numbers (which are then stored as bits). For example, 'A'
is 65 (01000001).
o UNICODE (UTF-8): A modern, vastly larger standard that includes characters
and emojis from all global languages, ensuring universal compatibility.
 IMAGE REPRESENTATION:
3
o PIXELS: A digital image is a grid of "picture elements" or pixels.
o COLOR DEPTH (RGB): Each pixel's color is stored, often as a combination of
Red, Green, and Blue values. A 24-bit "true color" system uses 8 bits (1 byte) for
each, allowing for ~16.7 million colors.
3: NETWORKING AND INTERNET CONCEPTS
 NETWORK TYPES:
o LAN (LOCAL AREA NETWORK): A network confined to a small
geographical area (e.g., a home, school, or single office building).
o WAN (WIDE AREA NETWORK): A network that spans a large geographical
area (e.g., connecting a bank's Lagos and Abuja offices). The Internet is the
largest WAN.
 THE INTERNET: A global "network of networks" that communicates using the
TCP/IP (Transmission Control Protocol/Internet Protocol) suite.
 IP ADDRESS: A unique numerical label (e.g., 172.217.14.228) assigned to every device
on a network. It acts like a digital street address.
 DNS (DOMAIN NAME SYSTEM): The "phonebook of the Internet." It translates
human-readable domain names (e.g., www.google.com) into machine-readable IP
addresses.

WEEK 2: ADVANCED WORD PROCESSING TECHNIQUES
TOPIC: MAIL MERGE, MACROS, AND TEMPLATES
INTRODUCTION: This week, we transition from basic document formatting to powerful
automation and professionalization tools within word processors. These skills are critical for
efficiency and consistency in academic and business environments.
1: MAIL MERGE IN-DEPTH
 THE CONCEPT: Mail merge is a process that automates the creation of personalized
mass documents (such as letters, labels, or emails). It combines a static "main document"
with a dynamic "data source" to produce a unique "merged document" for each recipient.
 THE THREE COMPONENTS OF MAIL MERGE:
6
1. THE MAIN DOCUMENT (THE TEMPLATE): This is the Word document
containing the boilerplate text (the content that is the same for everyone) and
special "merge fields" (e.g., <<First_Name>>) which act as placeholders for the
dynamic data.
2. THE DATA SOURCE (THE RECIPIENT LIST): This is the file that contains
the individual information. It is typically an Excel spreadsheet, a Word table, an
Outlook contact list, or a database file. The column headers (e.g., First_Name)
must match the merge fields.
3. THE MERGED DOCUMENT (THE RESULT): This is the final output, where
the placeholders are replaced with the actual data from each row of the data
source, creating a set of personalized documents.
 THE STEP-BY-STEP PROCESS (USING THE MAIL MERGE WIZARD):
1. START: Go to the "Mailings" tab and select "Start Mail Merge" -> "Step-by-Step
Mail Merge Wizard."
2. SELECT DOCUMENT TYPE: Choose "Letters," "E-mail Messages,"
"Envelopes," etc.
3. SELECT STARTING DOCUMENT: Choose "Use the current document."
4. SELECT RECIPIENTS: Choose "Use an existing list" and browse to your data
source (e.g., your Excel file).
5. WRITE YOUR LETTER: This is where you insert the "merge fields." Click
"Insert Merge Field" and add placeholders like <<Address>>, <<City>>, Dear
<<Title>> <<Last_Name>>.
6. PREVIEW YOUR LETTERS: You can scroll through each recipient's final
letter.
7. COMPLETE THE MERGE: You can "Print" directly or "Edit Individual
Documents" to create a new, large Word file containing all the merged letters.
2: AUTOMATION WITH MACROS
 THE CONCEPT: A macro is a recorded sequence of commands, keystrokes, and
actions that can be saved and executed (played back) with a single click or keyboard
shortcut.
7
 THE PURPOSE: To automate highly repetitive and complex tasks, saving time and
reducing human error.
 HOW TO RECORD A MACRO (NO CODING REQUIRED):
1. ENABLE THE DEVELOPER TAB: (File -> Options -> Customize Ribbon ->
Check "Developer").
2. START RECORDING: Go to the "Developer" tab and click "Record Macro."
3. ASSIGN: Give the macro a name (no spaces) and assign it to a button or
keyboard shortcut (e.g., Alt+C).
4. PERFORM ACTIONS: Every single click and keystroke is now being recorded.
For example:
 Change font to "Times New Roman."
 Change font size to "12."
 Set line spacing to "Double."
 Apply a first-line indent.
5. STOP RECORDING: Go to the "Developer" tab and click "Stop Recording."
 MACRO SECURITY (CRITICAL):
o Macros are powerful pieces of code (VBA - Visual Basic for Applications).
o MACRO VIRUSES are malicious programs embedded in documents. When the
document is opened and macros are enabled, the virus can execute, damaging files
or stealing data.
o RULE: Never enable macros from an untrusted source or an unexpected email
attachment.
3: PROFESSIONAL DOCUMENT TEMPLATES
 THE CONCEPT: A template is a pre-designed "blueprint" or "mold" for a document. It
is not a regular document.
 FILE EXTENSION: A standard Word document is .docx. A Word template is .dotx.
 THE DIFFERENCE: When you "open" a .docx, you are editing the original file. When
you "open" a .dotx, Word automatically creates a new, untitled document based on the
template, leaving the original template unchanged.
8
 WHY USE TEMPLATES?
1. CONSISTENCY: Ensures all company documents (letters, memos, reports) have
the same logo, font, and layout.
2. BRANDING: Reinforces a professional brand identity.
3. EFFICIENCY: Saves time by not having to recreate the layout for every new
document.
 CREATING A CUSTOM TEMPLATE:
1. Design your document (e.g., create a company letterhead and footer).
2. Go to "File" -> "Save As."
3. Change the "Save as type" dropdown from "Word Document (.docx)" to "Word
Template (.dotx)."
4. Save the file. It will now appear in your "Personal Templates" section.

WEEK 3: ADVANCED SPREADSHEET ANALYSIS I
TOPIC: PIVOT TABLES AND ADVANCED FORMULAS
INTRODUCTION: This week, we move beyond basic spreadsheet calculations (=SUM,
=AVERAGE) and into the realm of dynamic data analysis. Pivot tables are arguably the most
powerful data summarization tool in Excel, while logical and lookup functions allow you to
build "smart" spreadsheets that react to your data.
1: MASTERING PIVOT TABLES
 THE CONCEPT: A pivot table is an interactive data summarization tool that allows you
to quickly aggregate, analyze, and "pivot" (rearrange) large datasets without using any
formulas.
11
 THE PROBLEM PIVOT TABLES SOLVE: They transform a large, "flat" table (e.g.,
10,000 rows of sales data) into a dynamic and concise summary report (e.g., "Total sales
by region and product category").
 SOURCE DATA REQUIREMENTS: Your raw data must be "clean" and in a tabular
format:
1. Each column must have a unique header (e.g., "Date," "Salesperson," "Amount").
2. There must be no empty rows or columns within the data.
 THE PIVOT TABLE INTERFACE:
o FIELDS LIST: A list of all your column headers.
o ROWS AREA: Dragging a field here (e.g., "Region") creates a unique row for
each item in that field.
o COLUMNS AREA: Dragging a field here (e.g., "Product") creates a unique
column for each item.
o VALUES AREA: The "calculation engine." Dragging a numerical field here (e.g.,
"Amount") defaults to Sum. Dragging a text field defaults to Count.
o FILTERS AREA: Used to filter the entire report by a specific field.
 CREATING A PIVOT TABLE (STEP-BY-STEP):
0. Click anywhere inside your clean data.
1. Go to the "Insert" tab -> "PivotTable." Excel will auto-select your data.
2. Choose "New Worksheet" and click "OK."
3. Drag and drop your fields. Example:
 Drag "Region" to ROWS.
 Drag "Product" to COLUMNS.
 Drag "Amount" to VALUES.
4. You now have an instant summary table. You can "pivot" the data by dragging
"Region" to Columns and "Product" to Rows.
 MANIPULATING PIVOT TABLES:
o REFRESHING: Pivot tables do not update automatically. If you change the
source data, you must right-click the pivot table and select "Refresh."
12
o GROUPING: You can group dates (into months/quarters), numbers (into ranges),
etc.
2: ADVANCED FORMULAS AND FUNCTIONS
 LOGICAL FUNCTIONS (THE IF STATEMENT):
o PURPOSE: To make your spreadsheet return different results based on a
condition.
o SYNTAX: =IF(logical_test, value_if_true, value_if_false)
o EXAMPLE: =IF(A2 >= 50, "Pass", "Fail")
 logical_test: Is the value in cell A2 greater than or equal to 50?
 value_if_true: If yes, display "Pass."
 value_if_false: If no, display "Fail."
 NESTED IF STATEMENTS:
o PURPOSE: To handle multiple conditions by placing an IF statement inside
another IF statement.
o EXAMPLE (GRADING): =IF(A2 >= 70, "A", IF(A2 >= 60, "B", IF(A2 >= 50,
"C", "F")))
 LOOKUP FUNCTIONS (VLOOKUP):
o PURPOSE: To "vertically lookup" a value in one table and return a
corresponding value from another column.
o SYNTAX: =VLOOKUP(lookup_value, table_array, col_index_num,
[range_lookup])
o BREAKDOWN OF ARGUMENTS:
1. lookup_value: What you are looking for (e.g., a student's ID in cell A2).
2. table_array: Where to look. This is the lookup table (e.g., a separate table
E1:F50 containing all student IDs and their names). CRITICAL: The
lookup value must be in the first column of this table.
3. col_index_num: Which column's value to return from the table_array. (e.g.,
2 to return the student's name from the 2nd column).
4. [range_lookup]:
13
 FALSE (or 0): Exact Match. (99% of the time, you want this).
 TRUE (or 1): Approximate Match. (Used for tax brackets, etc.).
 CONDITIONAL AGGREGATION (SUMIF, COUNTIF, AVERAGEIF):
o PURPOSE: To sum, count, or average cells only if they meet a certain condition.
o SYNTAX: =SUMIF(range, criteria, [sum_range])
o EXAMPLE: =SUMIF(A1:A100, "Lagos", B1:B100)
 This will look in the range A1:A100 for the text "Lagos" and will only
sum the corresponding values from B1:B100.

WEEK 4: ADVANCED SPREADSHEET ANALYSIS II
TOPIC: FINANCIAL MODELS AND SCENARIO ANALYSIS
INTRODUCTION: This week, we leverage the power of spreadsheets to move from analyzing
the past (pivot tables) to forecasting the future. We will learn how to build basic financial
models and use "what-if" analysis tools to make informed business decisions.
1: INTRODUCTION TO FINANCIAL MODELING
 THE CONCEPT: A financial model is a spreadsheet-based simulation of a real-world
financial situation. It uses a set of inputs (assumptions) to calculate a set of outputs
(forecasts), allowing a user to see how a change in an assumption affects the outcome.
 PURPOSE:
1. FORECASTING: Predicting future revenue, profit, or cash flow.
2. BUDGETING: Planning for a company's or project's expenses.
16
3. DECISION MAKING: Determining the financial viability of a new project (e.g.,
"Should we open a new branch?").
 KEY PRINCIPLES OF GOOD MODELING:
1. ASSUMPTIONS-DRIVEN: All key inputs (e.g., "Price," "Sales_Growth_Rate")
should be in separate, clearly labeled cells. Never "hard-code" a number (e.g.,
A1*1.05) inside a formula. Instead, use A1 * B1, where B1 is a cell labeled
"Growth_Rate."
2. FLEXIBLE: The model should be easy to update. Changing an assumption in
one cell should cause the entire model to recalculate.
3. CLEAR AND SIMPLE: A good model is easy to understand, with clear labels
and formatting.
 BASIC EXAMPLE: A SIMPLE PROFIT/LOSS FORECAST:
o ASSUMPTIONS SECTION:
 Price per Unit = N1,000
 Cost per Unit = N400
 Units Sold = 500
o CALCULATIONS SECTION (THE MODEL):
 Revenue = Price per Unit * Units Sold (=N500,000)
 Cost of Goods Sold (COGS) = Cost per Unit * Units Sold (=N200,000)
 Gross Profit = Revenue - COGS (=N300,000)
2: SCENARIO ANALYSIS & "WHAT-IF"
 THE CONCEPT: Scenario analysis is the process of testing how a model's outputs (e.g.,
"Profit") change when one or more of the inputs (assumptions) are changed.
 THE "WHAT-IF" QUESTION: This answers questions like, "What if our units sold
are only 300?" or "What if the cost per unit increases to N500?"
 USING THE 'SCENARIO MANAGER' TOOL:
o Instead of manually changing the assumption cells, Scenario Manager allows you
to save different sets of assumptions as presets.
o LOCATION: "Data" tab -> "What-If Analysis" -> "Scenario Manager."
17
o PROCESS:
1. Click "Add" to create a scenario (e.g., "Best Case").
2. Select the "Changing cells" (your assumption cells, e.g., Price per Unit
and Units Sold).
3. Enter the values for that scenario (e.g., Price=N1,200, Units=700).
4. Repeat for "Worst Case" (e.g., Price=N900, Units=300).
5. You can now instantly toggle between these scenarios to see the profit
change.
3: THE 'GOAL SEEK' TOOL
 THE CONCEPT: Goal Seek is a "what-if" analysis tool that works backwards. You
specify the desired result (the "goal"), and Goal Seek finds the input value required to
achieve it.
 THE PROBLEM IT SOLVES: It answers questions like, "How many units must I sell
to achieve a profit of N500,000?" or "What price must I charge to break even (profit =
N0)?"
 HOW TO USE GOAL SEEK:
o LOCATION: "Data" tab -> "What-If Analysis" -> "Goal Seek."
o It has three simple fields:
1. SET CELL: The cell containing your final formula (e.g., the "Gross
Profit" cell).
2. TO VALUE: The numerical goal you want to achieve (e.g., 500000).
3. BY CHANGING CELL: The one assumption cell you want Excel to
change (e.g., the "Units Sold" cell).
o Click "OK," and Excel will run iterations until it finds the answer.

WEEK 6: ADVANCED PRESENTATION DESIGN AND DELIVERY
TOPIC: MULTIMEDIA INTEGRATION AND PROFESSIONAL DESIGN
INTRODUCTION: Most people use presentation software (like PowerPoint) poorly, creating
boring, text-heavy slides. This is known as "Death by PowerPoint." This week, we learn
advanced techniques to create dynamic, professional, and truly engaging multimedia
presentations.
1: PROFESSIONAL DESIGN PRINCIPLES (BEYOND BULLET POINTS)
 THE C.R.A.P. PRINCIPLES OF DESIGN: A simple framework for professional
layout.
1. CONTRAST: Make different elements (e.g., headline and text) really different.
Avoid similar fonts or colors. This creates visual interest.
21
2. REPETITION: Repeat key elements (fonts, colors, logos) throughout the
presentation. This creates a sense of unity and branding.
3. ALIGNMENT: Place every element intentionally. Align text and images to a
grid. Avoid "floating" elements. This creates an orderly, professional look.
4. PROXIMITY: Group related items close together. This creates logical sections
and reduces clutter.
 USING THE 'SLIDE MASTER' (THE MOST IMPORTANT EFFICIENCY
TOOL):
o LOCATION: "View" tab -> "Slide Master."
o CONCEPT: The Slide Master is not a slide in your presentation. It is the
"template" that controls all the slides.
o PURPOSE: If you want your company logo, a page number, or a specific font on
every single slide, you add it once to the Slide Master. This ensures 100%
consistency and saves you from copy-pasting.
2: MULTIMEDIA INTEGRATION
 INSERTING AND FORMATTING VIDEO:
o EMBEDDING VS. LINKING:
 LINKING: The video file remains separate. RISK: If you move the
presentation file without the video file, the link will break.
 EMBEDDING (RECOMMENDED): The video file is saved inside the
presentation file. This makes the file size larger, but it is safer and more
portable.
o VIDEO TOOLS: Once inserted, the "Playback" tab appears. You can:
 Trim the video (cut the start and end).
 Set it to "Play Automatically" or "On Click."
 Set it to "Loop Until Stopped."
 INSERTING AND FORMATTING AUDIO:
o NARRATION: You can record your own voice explaining each slide ("Record
Slide Show").
22
o BACKGROUND MUSIC: You can add a music file, set it to "Play in
Background," "Play Across Slides," and "Loop."
3: ADVANCED ANIMATIONS AND TRANSITIONS
 THE CRITICAL DIFFERENCE:
o TRANSITIONS: Affect how the entire slide enters or leaves the screen (e.g.,
Fade, Push).
o ANIMATIONS: Affect individual objects (text, images) on a slide (e.g., Appear,

TOPIC: THE FUNDAMENTALS OF WEB STRUCTURE AND STYLE
INTRODUCTION: This week, we begin one of the most important topics in Digital

1: THE CLIENT-SERVER MODEL
 WORLD WIDE WEB (WWW): A system of interlinked documents (websites)

INTRODUCTION: Now that we know the basics of HTML and CSS, we will learn the most

1: THE CSS BOX MODEL
 THE CONCEPT: Every single HTML element on your page is a rectangular box. The
CSS Box Model describes how this box is constructed.
 THE FOUR COMPONENTS (FROM INSIDE-OUT):
1. CONTENT: The actual text, image, or other content.
2. PADDING: The transparent space inside the border, between the content and the
border. It "pads" the content.
3. BORDER: The visible line or "frame" that surrounds the padding.
4. MARGIN: The transparent space outside the border. It "pushes" other elements
away.

 padding: 20px; /* 20px of space on all 4 sides, inside */

 }

 ID (FOR "IDENTIFICATION" - UNIQUE):
o HTML: <div id="main-header">...</div>

 <DIV> (DIVISION): A BLOCK-LEVEL container.
o A "block" element (like <h1>, <p>) always starts on a new line and takes up the

o A div is an empty, generic "box" used to group other elements for layout (e.g., a
div with id="container" to wrap your whole page).
 <SPAN>: AN INLINE container.
o An "inline" element (like <a>, <img>) sits within the flow of text and does not
start on a new line.
o A span is an empty, generic "inline box" used to style a part of a text.

WEEK 1: COMPUTER PROGRAMMING I
TOPIC: INTRODUCTION TO ALGORITHMS AND FLOWCHARTS
INTRODUCTION: This week, we begin the foundational study of computer programming.
Before a single line of code can be written, a programmer must have a clear, logical plan. This
plan is known as an algorithm. We will explore how to define these plans using plain language,
pseudocode, and visual diagrams called flowcharts.
1: UNDERSTANDING ALGORITHMS
 DEFINITION: An algorithm is a finite, step-by-step, unambiguous set of instructions
designed to solve a specific problem or perform a specific task.
 THE "RECIPE" ANALOGY: A good analogy is a cooking recipe. It has:
1. Inputs: Ingredients (e.g., flour, eggs, sugar).
2. Process: A set of instructions (e.g., "mix flour and eggs," "preheat oven").
40
3. Output: A finished product (e.g., a cake).
 PROPERTIES OF A GOOD ALGORITHM:
1. FINITE: It must terminate after a specific number of steps. It cannot run forever.
2. UNAMBIGUOUS: Each instruction must be perfectly clear, with only one
possible interpretation. A computer cannot "guess" your meaning.
3. INPUT: It must have zero or more well-defined inputs (the data it works with).
4. OUTPUT: It must produce one or more well-defined outputs (the result).
5. EFFECTIVE: Every instruction must be basic enough that it can be carried out,
in principle, by a person using only paper and pencil.
 REPRESENTING ALGORITHMS (PSEUDOCODE):
o DEFINITION: Pseudocode (meaning "false code") is a way of writing an
algorithm using plain English-like statements before translating it into a specific
programming language.
o PURPOSE: It allows the programmer to focus on the logic of the problem
without worrying about the syntax (the strict grammar rules) of a language like
Python or JavaScript.
o EXAMPLE: Algorithm to find the average of three numbers.
o START
o GET number1
o GET number2
o GET number3
o
o SET total = number1 + number2 + number3
o SET average = total / 3
o
o DISPLAY average
o END
2: VISUALIZING LOGIC WITH FLOWCHARTS
41
 DEFINITION: A flowchart is a visual, diagrammatic representation of an algorithm. It
uses a set of standard symbols connected by arrows to show the sequence of operations
and the flow of control.
 ADVANTAGES:
o CLARITY: Makes complex logic easy to understand at a glance.
o DEBUGGING: Helps to trace the logic and find errors (bugs) in the plan.
o DOCUMENTATION: Serves as a "blueprint" for the program, which helps in
team-based projects.
 STANDARD FLOWCHART SYMBOLS:
1. TERMINATOR (OVAL/ROUNDED RECTANGLE): Represents the START
and END (or STOP) points of the algorithm.
2. PROCESS (RECTANGLE): Represents an action or calculation (e.g., SET total
= a + b).
3. INPUT/OUTPUT (PARALLELOGRAM): Represents any action of getting
data (GET number) or displaying data (DISPLAY total).
4. DECISION (DIAMOND): Represents a question or a branching point. It has one
input arrow and two or more output arrows (e.g., "Yes/No" or "True/False"). (e.g.,
Is number > 10?).
5. FLOW LINES (ARROWS): Connect the symbols and show the direction of
logic.
6. CONNECTOR (CIRCLE): Used to connect a flowchart on the same page when
lines would cross.
3: EXAMPLES OF ALGORITHMS AND FLOWCHARTS
 EXAMPLE 1: SIMPLE PROCESS (ADDING TWO NUMBERS)
o Algorithm (Pseudocode):
o START
o GET num1
o GET num2
o SET sum = num1 + num2
42
o DISPLAY sum
o END
o Flowchart:
 START (Terminator) -> GET num1 (Input) -> GET num2 (Input) -> SET
sum = num1 + num2 (Process) -> DISPLAY sum (Output) -> END
(Terminator).
 EXAMPLE 2: A DECISION (IS A NUMBER EVEN OR ODD?)
o Algorithm (Pseudocode):
o START
o GET number
o
o SET remainder = number % 2 (The % is the Modulo operator, which finds the
remainder)
o
o IF remainder == 0 THEN
o DISPLAY "The number is Even"
o ELSE
o DISPLAY "The number is Odd"
o END IF
o
o END
o Flowchart:
 START (Terminator)
 -> GET number (Input)
 -> remainder = number % 2 (Process)
 -> Is remainder == 0? (Decision Diamond)
 -> (YES branch) -> DISPLAY "Even" (Output) ->
 -> (NO branch) -> DISPLAY "Odd" (Output) ->
 (Both branches then point to) -> END (Terminator).

WEEK 2: COMPUTER PROGRAMMING II
TOPIC: INTRODUCTION TO PYTHON AND JAVASCRIPT
INTRODUCTION: Now that we understand what an algorithm is, we must learn how to
translate our logical plans into a language a computer can understand. This week, we introduce
two of the most popular and powerful programming languages in the world: Python and
JavaScript.
1: PROGRAMMING LANGUAGE HIERARCHY
 LOW-LEVEL LANGUAGES:
o MACHINE CODE (FIRST GENERATION): The only language a CPU
understands. It is a sequence of binary digits (1s and 0s). It is unreadable by
humans.
o ASSEMBLY LANGUAGE (SECOND GENERATION): A human-readable
layer on top of machine code. It uses "mnemonics" (e.g., ADD, MOV) but is still
tied directly to the hardware.
 HIGH-LEVEL LANGUAGES (THIRD GENERATION):
45
o DEFINITION: Languages (like Python, JavaScript, Java, C++) that use Englishlike
syntax and mathematical notation, making them easy for humans to read,
write, and understand.
o ABSTRACTION: They "abstract away" (hide) the complex details of the
hardware (like memory management), allowing programmers to focus on solving
the problem.
 COMPILERS VS. INTERPRETERS: High-level code must be translated into lowlevel
machine code.
o COMPILER: Reads the entire program (source code) at once, translates it into
an executable file, and then runs it. (e.g., C++, Java).
o INTERPRETER: Reads and executes the program one line at a time. (e.g.,
Python, JavaScript).
o IMPLICATION: Interpreted languages are often easier to debug (you find the
error on the exact line) and more flexible, but compiled languages can be faster.
2: INTRODUCTION TO PYTHON
 HISTORY: Created by Guido van Rossum and first released in 1991. Named after
"Monty Python's Flying Circus."
 PHILOSOPHY (THE "ZEN OF PYTHON"): Emphasizes code readability, simplicity,

TOPIC: MEANING, APPLICATIONS, AND TOOLS OF BIG DATA
INTRODUCTION: "Data" is what we handled in Week 6 (e.g., a spreadsheet). "Big Data" is a

1: MEANING (THE 3 VS OF BIG DATA)
 DEFINITION: Big Data is defined by the "3 Vs" (or sometimes 5 Vs).
1. VOLUME (THE SIZE): The sheer amount of data being generated. We are no
longer talking about Megabytes (MB) or Gigabytes (GB), but Terabytes (TB),
Petabytes (PB), and Exabytes (EB).
66
 Example: Every flight of a 787 jet engine generates terabytes of sensor

2. VELOCITY (THE SPEED): The speed at which new data is being created and
must be processed.
 Example: Stock market data, Twitter posts (thousands per second), or realtime
GPS locations from millions of phones.
3. VARIETY (THE COMPLEXITY): The different types of data.
 Structured: Clean, organized data (e.g., an SQL database, an Excel sheet).
 Unstructured: "Messy" data (e.g., social media posts, emails, videos,
audio files, satellite images).
 Challenge: 80-90% of the world's data is unstructured.
2: APPLICATIONS OF BIG DATA ANALYTICS
 Big Data Analytics is the process of examining these massive datasets to uncover hidden

 REAL-WORLD APPLICATIONS:

3: TOOLS AND CONCEPTS (BRIEF)
 THE PROBLEM: A petabyte of data cannot be stored or processed on one single,

o CONCEPT: Instead of one super computer, you use a network (or "cluster") of

WEEK 10: MACHINE LEARNING BASICS
TOPIC: CONCEPT AND SIMPLE APPLICATIONS
INTRODUCTION: If AI is the broad goal of simulating human intelligence, Machine
Learning (ML) is the primary method for achieving it. ML is a subfield of AI, and it is the
technology that powers most of the modern AI applications we use every day.
1: MACHINE LEARNING VS. TRADITIONAL PROGRAMMING
 TRADITIONAL PROGRAMMING (WHAT WE DID IN WEEKS 1-4):
o We (the programmer) write explicit rules (like if-elif-else) to tell the computer
exactly what to do.
o Input: Data
o Program: Rules
o Output: Answer
o Problem: What about a spam filter? You cannot possibly write a rule for every
single "spam" word.
 MACHINE LEARNING (THE NEW PARADIGM):
73
o We (the programmer) feed the computer data and examples of the answers, and
the machine learns the rules on its own.
o Input: Data + Example Answers
o Program: Machine Learning Algorithm
o Output: A "Model" (which is the set of rules the machine learned)
2: HOW MACHINE LEARNING WORKS (SPAM FILTER ANALOGY)
1. TRAINING:
o You get a dataset of 100,000 emails.
o You manually label each one: "Spam" or "Not Spam" (these are the "example
answers").
o You feed this labeled data into an ML algorithm.
2. LEARNING:
o The algorithm "learns" the patterns. It discovers which words (e.g., "Winner,"
"Free," "Viagra") are highly correlated with a "Spam" label.
o The output is a Model (a set of rules and correlations) that can predict the
"spamminess" of an email.
74
3. PREDICTION (INFERENCE):
o A new, unseen email arrives.
o You feed it into your trained Model.
o The Model gives it a "spam score" (e.t., 95% likelihood of being spam) and
makes a prediction.
3: TYPES OF MACHINE LEARNING (SIMPLE)
1. SUPERVISED LEARNING (LEARNING WITH LABELS):
o This is the spam filter example. The data is "supervised" because it is fully
labeled with the correct answers.
o The goal: To make predictions.
o Examples:
 Classification: Predicting a category (e.g., "Spam/Not Spam," "Cat/Dog,"
"Fraud/Not Fraud").
 Regression: Predicting a number (e.g., "What will be the price of this
house?", "How many points will this player score?").
2. UNSUPERVISED LEARNING (LEARNING WITHOUT LABELS):
75
o The data has no labels. You don't know the "right" answer.
o The goal: To find hidden patterns or structures in the data.
o Examples:
 Clustering: Automatically grouping data points into clusters. (e.g., A
marketing company grouping customers into "high-spenders," "bargainhunters,"
and "new-users" based on their shopping habits, without
knowing those groups beforehand).
 Anomaly Detection: Finding data points that don't fit any pattern (e.g.,
finding a weird sensor reading, which could be fraud or a broken machine).
4: COMMON APPLICATIONS
 Spam Filters: (Supervised Classification)
 Recommendation Engines (Netflix, Jumia): (Unsupervised Clustering, Supervised
Regression)
 Facial Recognition: (Supervised Classification)
 Medical Diagnosis: (Supervised Classification)
 Customer Segmentation: (Unsupervised Clustering)
76

WEEK 3: CLOUD COMPUTING II

INTRODUCTION: We have previously discussed cloud computing as "on-demand computing

WEEK 4: BLOCKCHAIN TECHNOLOGY
TOPIC: CONCEPT, CRYPTOCURRENCY, AND USES BEYOND FINANCE
INTRODUCTION: "Blockchain" is one of the most hyped and misunderstood technologies of
the last decade. It is not just "Bitcoin." Bitcoin is just the first application of blockchain. At its
core, a blockchain is a new and powerful way to store and secure data.
1: WHAT IS A BLOCKCHAIN?
 THE "DIGITAL LEDGER" ANALOGY:
o Imagine a "ledger" (a record book or Excel sheet) that tracks transactions.
o This ledger is DISTRIBUTED: It is not stored in one central place (like a bank's
server). Instead, a copy of the entire ledger is given to thousands of computers
(called "nodes") all over the world.
o This makes it DECENTRALIZED: No single person, company, or government
owns or controls the network.
 THE "BLOCKS" AND THE "CHAIN":
93
o When a new transaction occurs (e.g., "Adebayo pays Bisi 1 coin"), it is bundled
into a "block" with other recent transactions.
o This "block" is verified by the network and then cryptographically "chained" to
the end of the previous block, creating a chain of blocks.
o This cryptographic link makes the ledger IMMUTABLE: Once a block is added,
it is practically impossible to change or delete it. To do so, you would have to
change the block on more than 51% of the computers on the network at the exact
same time.
2: KEY PROPERTIES OF BLOCKCHAIN
1. DECENTRALIZATION: No single point of failure. The network is run by its
participants.
2. IMMUTABILITY: The data, once written, cannot be altered. This creates trust.
3. TRANSPARENCY: Everyone on the network can view the (anonymized) history of
transactions.
4. SECURITY: Secured by advanced cryptography and the distributed nature of the
network.
3: APPLICATION 1 - CRYPTOCURRENCY
 DEFINITION: A "cryptocurrency" is a digital or virtual currency that uses cryptography
for security. It is the first and most famous use-case for blockchain.
 BITCOIN (BTC): The first decentralized cryptocurrency, created in 2009 by the
anonymous "Satoshi Nakamoto." Its blockchain is a public ledger that only records the
transfer of Bitcoin from one "wallet" to another.
 ETHEREUM (ETH): The second-largest cryptocurrency. Its blockchain is more
advanced. It doesn't just track money; it can also run computer programs.
4: APPLICATIONS BEYOND FINANCE
 This is the true future of the technology.
 1. SUPPLY CHAIN MANAGEMENT:
94
o PROBLEM: Where did this product come from? Is it a fake?
o SOLUTION: A company (e.g., a luxury brand or a food company) can use a
blockchain to track a product from its creation (the farm, the factory) to the store
shelf. Each step is a "block." The customer can scan a QR code to see the entire,
immutable history of their product, proving it is authentic.
 2. "SMART CONTRACTS" (ON ETHEREUM):
o DEFINITION: These are not legal contracts, but small computer programs that
are stored and run on the blockchain.
o FUNCTION: They automatically execute an agreement. "IF-THEN" logic.
o EXAMPLE: "IF the shipping company's GPS (connected to the blockchain)
reports the package is 'Delivered', THEN automatically release the payment from
the buyer to the seller." This removes the need for a "middleman" to hold the
money.
 3. VOTING SYSTEMS:
o PROBLEM: Voting can be rigged, and ballots can be "lost" or changed.

would be secure, anonymous, transparent (anyone could count the votes), and
immutable (no one could change a vote after it's cast).
 4. NON-FUNGIBLE TOKENS (NFTS):
o A way to prove ownership of a unique digital item (like digital art, music, or
collectibles) on the blockchain.

WEEK 6: CYBERSECURITY III
TOPIC: ETHICAL HACKING AND PENETRATION TESTING
INTRODUCTION: We have previously discussed cybersecurity in terms of defense (passwords,
firewalls). This week, we learn about proactive defense, also known as "offensive security." The
best way to protect a system is to think like a hacker and find your own weaknesses before a
criminal does. This is the job of an "Ethical Hacker."
1: THE "HACKER HATS" (TYPES OF HACKERS)
 1. WHITE HAT HACKER:
o THE "GOOD GUY." Also known as an "Ethical Hacker" or "Security
Researcher."
o MOTIVATION: To help companies.
o METHOD: Hacks with explicit, written permission from a company to find
vulnerabilities. Their goal is to fix security holes.
o LEGALITY: 100% legal. This is a high-paying, in-demand job.
 2. BLACK HAT HACKER:
98
o THE "CRIMINAL." Also known as a "Malicious Hacker."
o MOTIVATION: Personal gain (money), revenge, espionage, or pure destruction.
o METHOD: Hacks without permission. Steals data (credit cards, PII), deploys
ransomware, or destroys systems.
o LEGALITY: 100% illegal. This is a crime.
 3. GREY HAT HACKER:
o THE "IN-BETWEEN."
o MOTIVATION: Ambiguous. Often hacks for fun, to show off, or for "vigilante"
justice.
o METHOD: Hacks without permission (like a Black Hat), but may report the
vulnerability to the company (like a White Hat). They might also demand a "bug
bounty" (payment) to fix it, which borders on extortion.
o LEGALITY: Illegal. Accessing a system without permission is a crime,
regardless of intent.
2: WHAT IS PENETRATION TESTING (PEN-TESTING)?
99
 DEFINITION: A Penetration Test (or "Pen-Test") is the formal, authorized, and
simulated cyberattack on a computer system, network, or application to evaluate its
security.
 GOAL: To find and exploit vulnerabilities in a safe and controlled manner, before a
Black Hat hacker can.
 THE DELIVERABLE: The final "product" of a pen-test is not the "hack"; it is a
detailed report that explains:
1. What vulnerabilities were found.
2. How they were exploited (step-by-step).
3. The risk to the business (e.g., "We were able to steal all customer data").
4. The recommendations for fixing the vulnerabilities.
3: THE 5 PHASES OF A PENETRATION TEST
1. 1. RECONNAISSANCE (INFORMATION GATHERING):
o "Casing the joint." The hacker gathers as much public information as possible
about the target (e.g., employee names from LinkedIn, technologies used, IP
addresses).
2. 2. SCANNING:
o The hacker actively "touches" the target's network.
o Uses tools (like Nmap) to scan for open "ports" (doors), what services are running
(e.g., web server, database), and what software versions they are using.
3. 3. GAINING ACCESS (EXPLOITATION):
o The "hack." The ethical hacker uses a known vulnerability (e.g., an unpatched
server, a weak password) or a "payload" to get inside the system.
4. 4. MAINTAINING ACCESS:
o The hacker tries to stay in the system, "pivot" to other systems on the network,
and "escalate privileges" (e.g., moving from a normal user to a "root" or "admin"
user).
5. 5. COVERING TRACKS & REPORTING:
o A Black Hat would delete logs to hide their presence.
100
o A White Hat securely documents every step and writes the final report for the
client.
4: COMMON ATTACK VECTORS
 SOCIAL ENGINEERING: Hacking the human. This is the most common attack vector.
o PHISHING: A mass e-mail campaign that looks legitimate (e.g., from your bank)
to trick you into clicking a malicious link or entering your password.
o SPEAR PHISHING: A highly targeted phishing attack on one specific person
(e.g., the CFO).
o PRETEXTING: A phone call where the hacker pretends to be someone else (e.g.,
"Hello, this is IT, I need your password to apply a security patch").
 TECHNICAL ATTACKS:
o UNPATCHED SOFTWARE: Running old, outdated software with known
security holes. This is the most common technical vector.
o SQL INJECTION (SQLI): An attack that targets a website's database by
"injecting" malicious code into a form (like a search bar).
o CROSS-SITE SCRIPTING (XSS): An attack that injects malicious code into a
website, which then runs in the victim's browser.
EVALUATION

WEEK 8: CYBER LAWS AND DIGITAL RIGHTS
TOPIC: THE NIGERIAN CYBERCRIME ACT AND GLOBAL CYBER LAWS
INTRODUCTION: As technology becomes more integrated into our lives, our laws must adapt
to govern the digital space. "Cyber Law" (or "Cybercrime Law") is the field of law that deals
with legal issues related to the internet and information technology. This week, we will focus on
Nigeria's primary cyber law and the global concept of "Digital Rights."
1: THE NIGERIAN CYBERCRIME (PROHIBITION, PREVENTION, ETC.) ACT 2015
 PURPOSE: This is the primary legislation governing online activity in Nigeria. Its full
title outlines its goals: "An Act to provide for the prohibition, prevention, detection,
prosecution and punishment of cybercrimes in Nigeria; and for other related matters."
 WHAT DOES IT DO? It officially makes "cybercrime" a crime. Before this act, it was
difficult to prosecute someone for a purely digital offense.
 KEY PROVISIONS (SIMPLIFIED):
o ILLEGAL ACCESS (HACKING): Makes it illegal to access a computer system
or network without authorization (Section 6).
104
o DATA FORGERY (FRAUD): Makes it illegal to alter or forge digital data to
commit fraud (Section 7).
o IDENTITY THEFT: Makes it illegal to use another person's identity, email, or
credentials online (Section 13).
o PHISHING & SPAM: Prohibits sending fraudulent messages ("phishing") and
unsolicited bulk messages ("spam") (Sections 14, 15).
o CHILD PORNOGRAPHY: Strictly prohibits the creation, distribution, and
possession of child pornography (Section 23).
o CYBER-SQUATTING: Makes it illegal to register a domain name (website
address) that is the same as a registered trademark or brand, with the bad-faith
intent to profit from it (Section 25).
 CONTROVERSIAL PROVISION (SECTION 24):
o This section, titled "Cyber-stalking," is the most widely discussed.
o It criminalizes sending a message or "causing a message to be sent" through a
computer system that is:
 (a) "grossly offensive, indecent, obscene or menacing"
 (b) "for the purpose of... causing annoyance, inconvenience, danger,
obstruction, insult, injury, criminal intimidation, enmity, hatred, ill will or
needless anxiety..."
o THE DEBATE: While intended to stop cyber-bullying and harassment, critics
argue that terms like "annoyance" and "insult" are too vague and could be used to
suppress free speech or arrest journalists and critics.
2: GLOBAL CYBER LAWS (GDPR)
 GDPR (GENERAL DATA PROTECTION REGULATION):
o WHAT IS IT? A data privacy and security law from the European Union (EU).
o WHY DOES IT MATTER TO NIGERIA? It has "extra-territorial" scope. This
means if any Nigerian company (e.g., a bank, an e-commerce site) offers services
to, or processes the data of, any person in the EU, that Nigerian company must
comply with the GDPR.
 CORE PRINCIPLES OF GDPR:
105
1. "DATA SUBJECT" RIGHTS: It gives control back to the user.
2. EXPLICIT CONSENT: Companies must ask for your permission in clear,
simple language. No more pre-ticked boxes.
3. RIGHT TO ACCESS: You can ask any company, "What data do you have on
me?" and they must tell you.
4. RIGHT TO BE FORGOTTEN: You can demand that a company delete your
personal data.
3: DIGITAL RIGHTS
 DEFINITION: The concept that human rights (like freedom of speech) are not "lost"
when you go online. These are the fundamental freedoms that apply to the digital world.
 KEY DIGITAL RIGHTS:
1. RIGHT TO FREEDOM OF EXPRESSION: The right to express your opinions
online, even if they are critical of a government or corporation. (This is often
debated against "hate speech").
2. RIGHT TO PRIVACY: The right to be free from unreasonable government or
corporate surveillance. The right to use encryption to protect your
communications.
3. RIGHT TO ACCESS: The idea that all people should have the ability to access
and use the internet. The "digital divide" (the gap between those with and without
access) is a major human rights issue.

WEEK 9: DIGITAL ENTREPRENEURSHIP
TOPIC: E-COMMERCE, FREELANCING, AND ONLINE BUSINESS
INTRODUCTION: "Entrepreneurship" is the act of creating a business to solve a problem.
"Digital Entrepreneurship" is simply using the internet and digital tools to build, run, and scale
that business, often with far lower startup costs than a traditional "brick-and-mortar" company.
1: E-COMMERCE (ELECTRONIC COMMERCE)
 DEFINITION: The buying and selling of goods (like a phone) or services (like a Netflix
subscription) over the internet.
 KEY E-COMMERCE MODELS:
1. B2C (BUSINESS-TO-CONSUMER): The most common model. A business
sells directly to an individual customer.
 Example: Jumia, Konga, or a local restaurant's website.
2. B2B (BUSINESS-TO-BUSINESS): A business sells its products or services to
other businesses.
108
 Example: A software company that sells accounting software to law firms,
or a company that sells bulk office supplies.
3. C2C (CONSUMER-TO-CONSUMER): A platform that enables individuals to
sell their (often used) goods to other individuals.
 Example: Jiji.ng, eBay, Facebook Marketplace.
 THE "DROP-SHIPPING" MODEL:
o This is a popular B2C model.
o THE PROCESS:
1. You (the entrepreneur) create a beautiful website (e.g., using Shopify) and
market a product (e.g., a "Smart Watch").
2. A customer buys the watch from your site for N15,000.
3. You automatically forward that order to your supplier (e.g., a factory in
China).
4. You pay the supplier their price (e.g., N5,000).
5. The supplier ships the watch directly to the customer, with your brand on
it.
o PROS: You never have to buy or store any inventory.
o CONS: You don't control shipping times or product quality.
2: FREELANCING (THE GIG ECONOMY)
 DEFINITION: Being self-employed and offering your digital skills as a service to
clients on a project-by-project basis. You are your own boss.
 WHAT SKILLS CAN YOU FREELANCE?
o TECH: Web development, app development, data analysis.
o CREATIVE: Graphic design, video editing, writing, voice-over acting.
o ADMIN: Virtual assistant, social media management, data entry.
 FREELANCING PLATFORMS: These are the "marketplaces" that connect freelancers
with clients.
o Upwork: A "bidding" model. Clients post a job, and freelancers bid on it.
109
o Fiverr: A "gig" model. Freelancers post their services (e.g., "I will design a logo
for $50"), and clients buy them.
o Toptal: An exclusive, high-end platform for the "Top 3%" of developers.
 PROS:
o Flexibility (work from anywhere, set your own hours).
o You are your own boss.
 CONS:
o No stable salary (income can be inconsistent).
o You are responsible for everything: finding clients, marketing, taxes, etc.
3: DIGITAL MARKETING (GETTING CUSTOMERS)
 An online business is useless if no one knows it exists. Digital Marketing is the process
of attracting customers online.
 KEY METHODS:
1. SOCIAL MEDIA MARKETING (SMM): Using platforms like Instagram,
TikTok, and Facebook to build a brand, engage with customers, and run targeted
ads.
2. SEARCH ENGINE OPTIMIZATION (SEO): The "organic" (free) process of
optimizing your website (e.g., with good keywords) so it appears as the first result
on Google.
3. CONTENT MARKETING: Creating valuable content (e.g., a blog, a "how-to"
YouTube video) that attracts customers by solving their problems, rather than just
running ads.
